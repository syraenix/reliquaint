# DOSBox Staging Guides

This repo contains guides for configuring and running various DOS games using DOSBox Staging.

> DOSBox Staging was chosen over DOSBox due to a [known issue with arrow keys not working] correctly in DOSBox.

## Prerequisites

Follow the steps in the [prerequisites guide](docs/prerequisites.md) to install the software required to complete the game guides.

## Game Guides

The individual games guides include instructions and scripts for downloading, extracting, cofiguring, and running the games.

- [Quest for Glory Collection](quest-for-glory-collection/quest-for-glory-collection.md)
