# Classic Game Installation Guides

This repo contains guides for configuring and running classic games on Linux — DOS games via DOSBox Staging and Amiga games via FS-UAE.

## Prerequisites

Follow the steps in the [prerequisites guide](docs/prerequisites.md) to install the software required to complete the game guides.

## Game Guides

The individual games guides include instructions and scripts for downloading, extracting, configuring, and running the games.

- [Amiga](amiga/amiga.md)
- [King's Quest](dos/kings-quest/kings-quest.md)
- [Quest for Glory](dos/quest-for-glory/quest-for-glory.md)
